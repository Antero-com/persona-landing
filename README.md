# Лендинг «Persona»

Статический сайт: HTML, CSS и JavaScript без сборки. Подходит для GitHub Pages. Изображения сцены лежат отдельными файлами, так что их легко заменить.

## Перед публикацией: Яндекс Форма

Личные Яндекс Формы доступны бесплатно. Ответы видит владелец формы в разделе **Ответы**; в **Интеграции → Почта** можно включить письма на свой адрес. Для командной работы с доступом нескольких сотрудников Яндекс предлагает отдельную версию для бизнеса. Справка: [личные и бизнес-формы](https://yandex.ru/support/forms/ru/go-to-forms), [ответы](https://yandex.ru/support/forms/ru/answers), [почтовые уведомления](https://yandex.ru/support/forms/ru/send-mail).

1. Войдите в [личные Яндекс Формы](https://forms.yandex.ru/admin/) и создайте пустую форму «Persona — заявка на интервью». В описании укажите, что выбранный час по Москве — пожелание, а день и время команда подтвердит отдельно.
2. Добавьте обязательные вопросы в таком порядке:
   - **Как с тобой связаться?** — «Один вариант»: `Электронная почта`, `Telegram`. Добавьте вопрос типа «Почта», который показывается при первом ответе, и «Короткий текст» для публичного `@username`, который показывается при втором. Оба вопроса сделайте обязательными при их показе.
   - **Удобная дата** — вопрос «Дата», обязательный.
   - **Удобное время (МСК)** — вопрос «Выпадающий список», обязательный. Варианты по одному часу: `10:00–11:00`, `11:00–12:00`, `12:00–13:00`, `13:00–14:00`, `14:00–15:00`, `15:00–16:00`, `16:00–17:00`, `17:00–18:00`, `18:00–19:00`, `19:00–20:00`.
   - **Какой разговор хотелось бы переиграть?** — «Выпадающий список»: `С друзьями`, `На учёбе`, `В очереди или другом общественном месте`, `Пока не знаю`.
   - **Что заинтересовало сильнее?** — «Выпадающий список»: `Выбор реплики`, `Возможность ответить голосом`, `Разбор после истории`, `Пока не знаю`.
   - **Согласие на обработку данных** — отдельный обязательный вопрос «Несколько вариантов» с единственным вариантом `Согласен(на)`. В формулировке укажите реального оператора данных и цели: связь по интервью и приглашение в ранний тест. Добавьте прямую ссылку на опубликованную `privacy.html` и адрес для отзыва согласия. Не отмечайте вариант заранее.
     Пример текста для вопроса: `Я даю согласие [ФИО/наименование оператора] на обработку моего контакта, предпочтительных даты и времени и ответов на два вопроса для связи по интервью и приглашения в ранний тест. Политика: [полная ссылка на privacy.html]. Отозвать согласие: [адрес команды].` Замените все скобки на реальные сведения.
3. Откройте вкладку **Тема** и задайте светлый фон `#f8f1e6`, тёмный текст `#171b19`, жёлтую кнопку `#ffd36c`, квадратные поля, если доступны в редакторе. Сам внешний каркас формы уже оформлен на сайте. [Настройка темы](https://yandex.ru/support/forms/ru/appearance).
4. В **Интеграции → Почта** включите действие «Почта» и в поле **Кому** выберите `Email автора формы` или укажите рабочий адрес. Для заявки с персональными данными предпочтительна почта, которую команда использует и контролирует в России. Ответы остаются доступны в кабинете формы и без уведомлений.
5. Опубликуйте форму, скопируйте **ссылку** вида `https://forms.yandex.ru/u/ИДЕНТИФИКАТОР/` (не весь HTML-код iframe). В `config.js` заполните `yandexFormUrl`, `operatorName` — ФИО/ИП/наименование фактического оператора данных, и проверьте `teamEmail` — контакт из подвала сайта для запросов по данным. Пока одно из этих полей не заполнено, внешний iframe не загружается и сайт показывает сообщение об ожидании. [Публикация и встраивание](https://yandex.ru/support/forms/ru/publish).
6. Проверьте `privacy.html`: название оператора и контакт, цели, срок хранения **не более 12 месяцев** и фактический порядок удаления ответов должны соответствовать вашей практике. В форме должна быть отдельная отметка согласия. Уточните у организаторов конкурса, соответствует ли им бесплатная личная форма, и проверьте обязанности оператора персональных данных до открытия сбора заявок.
7. Отправьте тестовую заявку с опубликованного сайта. Проверьте часовые варианты, раздел **Ответы** в Яндекс Формах, почтовое уведомление и возможность отправить запрос на удаление данных.

Не спрашивайте через эту форму сведения о здоровье или другие чувствительные данные: условия Яндекс Форм исключают специальные категории персональных данных. Обещание премиум аккаунта на год добавлено в тексты: до публикации команда должна подтвердить, что сможет выдать его участникам интервью.

## Публикация через GitHub Pages

1. Создайте новый репозиторий GitHub, например `persona-landing`. Для простого варианта используйте публичный репозиторий.
2. Загрузите **содержимое этой папки** в корень репозитория: `index.html`, `privacy.html`, `styles.css`, `script.js`, `config.js`, `.nojekyll` и папку `assets`. Не загружайте внешнюю папку `persona-landing` как единственный объект.
3. В репозитории откройте **Settings → Pages**. В **Build and deployment → Source** выберите **Deploy from a branch**. Выберите ветку `main`, папку `/(root)` и нажмите **Save**.
4. Подождите публикации; адрес появится в разделе Pages. Для репозитория `persona-landing` он обычно выглядит как `https://ВАШ_ЛОГИН.github.io/persona-landing/`.
5. Проверьте на опубликованном адресе сцену, выбор реплик, форму и страницу обработки данных. Затем используйте этот адрес в сообщениях Telegram и VK.

Альтернатива через терминал из этой папки после создания **пустого** репозитория:

```bash
git init
git branch -M main
git add .
git commit -m "Add PersonA landing"
git remote add origin https://github.com/ВАШ_ЛОГИН/persona-landing.git
git push -u origin main
```

Не храните в репозитории пароли и серверные ключи. Публичную ссылку на Яндекс Форму можно хранить в `config.js`.

## Замена изображений и фона

- `assets/clinic-corridor.webp` — задний фон игрового эпизода.
- `assets/grandmother-neutral.webp` и `assets/grandmother-neutral-talk.webp` — бабушка в спокойном состоянии и кадр речи.
- `assets/grandmother-grateful.webp` и `assets/grandmother-grateful-talk.webp` — благодарное выражение после ответа «Проходите».
- `assets/grandmother-smug.webp` и `assets/grandmother-smug-talk.webp` — ухмылка после ответа про запись.

После замены сцены прежние шесть файлов `assets/elder-*.webp` больше не используются; при желании их можно удалить из репозитория.

Если новые файлы имеют те же имена, просто замените их в `assets/`. При других именах поменяйте `src` фона и начального персонажа в `index.html`, а пути шести кадров в объекте `characterFrames` в `script.js`. У кадров персонажа должен совпадать размер холста и положение головы, иначе при анимации он будет «прыгать». Композиция, размеры и положение слоёв настраиваются в `styles.css` в правилах `.scene-background` и `.scene-character`. Комиксный точечный узор и цвета всей страницы также находятся в `styles.css`, в начале файла.

Для проверки на компьютере из этой папки:

```bash
python3 -m http.server 8000
```

Затем откройте `http://localhost:8000/`. Кнопки игровой сцены показывают заранее написанные варианты реакции, выражения лица и короткую анимацию речи. Свой текст в этом концепте не отправляется в ИИ и никуда не сохраняется. Если браузер поддерживает распознавание речи, рядом с текстовым полем появляется кнопка микрофона.
